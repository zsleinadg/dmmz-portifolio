## Experiência — Projetos

### Leivices — Agendamentos Online e Gerenciamento de Salões
_SaaS multi-inquilino para salões de beleza, barbearias e clínicas de estética_

Sistema completo com agendamento inteligente (bloqueio automático de conflitos), gestão de equipe com comissões por profissional, painel analítico com gráficos interativos e métricas de desempenho. Implementa autenticação via NextAuth com perfis OWNER/CLIENT, assinaturas recorrentes gerenciadas pelo Stripe (TRIAL, BASIC, PROFESSIONAL, ENTERPRISE), upload de mídias com Cloudinary, notificações transacionais via Resend e geração de recibos em PDF. Stack: NextJS, TypeScript, PostgreSQL, PrismaORM, Stripe, TailwindCSS, NextAuth, TanStack React Query, Recharts, Zod + React Hook Form.

### Forno-Pizzaria — Ecossistema Full-Stack para Gestão de Pedidos
_Backend, Web e Mobile integrados para gestão de pizzarias_

Ecossistema completo utilizando PostgreSQL com PrismaORM para persistência de dados e RBAC com roles ADMIN e STAFF. Painel web para gerenciamento de categorias, produtos e fluxo de ordens, e aplicativo mobile (Expo/React Native) para garçons otimizarem a criação de pedidos e comunicação com a cozinha.

### WebCarros — Plataforma SaaS de Marketplace Automotivo
_Sistema completo de anúncios com integração WhatsApp_

Gerencia autenticação de usuários, persistência em tempo real e storage para múltiplos arquivos com Supabase. Implementa validações rigorosas com Zod + React Hook Form e integração dinâmica com WhatsApp para conversão de leads.

### English Tutor — Tutoria de Inglês com Inteligência Artificial
_Plataforma de ensino personalizada com API Groq (LPU)_

Sistema de tutoria em tempo real com baixíssima latência que fornece correções gramaticais, explicações contextuais e sugestões de reescrita. Inclui motor de avaliação com score de proficiência detalhado, analisando pontos fortes e áreas de melhoria a cada interação.

### DalyGames — Portal de Catálogo de Jogos
_Portal dinâmico com recomendações diárias e SSR_

Catálogo vasto de jogos via consumo de APIs externas com algoritmo de seleção aleatória para "Recomendação do Dia". Utiliza Server-Side Rendering (SSR) com Next.js para performance e SEO, com páginas de detalhes ricas em metadados e mídia.
